# Bug Days - Development Ground Rules

## UI/UX Principles

1. **No Horizontal Scroll** - Strictly avoid horizontal scrolling unless absolutely necessary
2. **Responsive/Adaptive Design** - All pages must work on phone screens through UHD monitors
3. **Minimize Vertical Space** - Keep vertical footprint compact without cramping the layout

## Design System

- **Primary Accent**: Indigo-600 (#4f46e5) with purple undertones
- **Color Palette**: White/slate base with indigo/purple accents
- **Layout**: Left sidebar navigation with grouped tools
- **Mobile**: Overlay sidebar triggered by hamburger menu
- **Desktop**: Always-visible sticky sidebar
